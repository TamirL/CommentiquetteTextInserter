## Scoring rules (as agreed)

| What you captured | Points |
| --- | --- |
| Each **8** | 1 each (4 in the deck → 4 pts) |
| Each **Jack** | 1 each (4 in the deck → 4 pts) |
| **2 of clubs** | 2 |
| **10 of diamonds** | 3 |
| **Majority of cards** at the end of the game | 3 (independent of everything else) |
| Each **Basra** | 1 each (a player can score many in one game) |

Fixed card points per game: 4 (eights) + 4 (jacks) + 2 (2♣) + 3 (10♦) = **13**, plus **3** for the card majority = **16**, plus 1 per Basra on top.

> Note: the 2♣ and the 10♦ are scored only by their special value — they're not an 8 or a Jack, so there's no double counting.
> Note: "two o'clock" is written down here as the **2 of clubs**. Say the word if you meant something else and I'll change it.
> Note: these use **8s** as the 1-pointers. (The common Basra variant uses aces there — we're playing eights.)
